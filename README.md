# Overview

MoneyCoin is a modern financial dashboard developed entirely with **HTML**, **CSS** and **Vanilla JavaScript**.

The project was designed to simulate the experience of professional financial platforms while remaining lightweight, fast and fully deployable on GitHub Pages without requiring backend services or paid APIs.

The interface focuses on readability, responsiveness and data visualization, combining financial information with a clean and intuitive design.

# Design Philosophy

The interface was inspired by:

- Yahoo Finance
- Coinbase
- TradingView

while maintaining its own visual identity.

The goal was to prioritize:

- information hierarchy
- clean typography
- white space
- smooth interactions
- performance
- usability
